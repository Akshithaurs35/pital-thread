# Petal & Thread — Women's Dresses Website

A responsive women's dress boutique demo made with HTML, CSS, and vanilla JavaScript.

## Files

- `index.html` — page structure and content
- `styles.css` — styling and responsive layout
- `app.js` — product catalogue, wishlist, cart quantities, and subtotal
- `README.md` — project instructions

## Run the website

1. Keep all four files in the same folder.
2. Double-click `index.html` to open it in your browser.
3. An internet connection is needed for the remote product photos and Google Fonts.

## Features

- Women's dresses only: floral, everyday, maxi, midi, and occasion styles
- Product photos, names, prices, sale prices, and ratings
- Add to cart, with each product's quantity shown on its product card after adding
- Plus and minus quantity buttons directly on product cards
- Bag/cart count shows the total number of items
- Cart drawer shows each item's quantity, line total, and total subtotal
- Remove individual products from the cart
- Wishlist buttons and wishlist count
- Search, category filter, and sorting by price or rating
- Responsive layout for phones and desktop
- Cart and wishlist persist in the same browser using `localStorage`

## Important

This is a frontend demo for practice. Checkout does not process payments. Product photos load from Unsplash, so internet access is required. Cart and wishlist are stored only in your browser.
